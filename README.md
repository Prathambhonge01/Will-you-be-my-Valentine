# Will You Be My Valentine? 💖✨

An interactive, playful, and animated Valentine's Day proposal website built with modern HTML5, CSS3, and JavaScript!

## ✨ Features & Fun Effects

- 🌸 **Ambient Floating Hearts & Petals**: Smooth HTML5 canvas animation with floating hearts, blossoms, and sparkles.
- ✨ **Interactive Cursor Trail**: Generates glowing mini-hearts and stars as the user moves their mouse or taps on mobile.
- 😈 **Playful "No" Button Shenanigans**:
  - Cycles through 15 increasingly funny, dramatic, and desperate pleading messages.
  - Dynamically switches GIFs from cute asking to shocked, teary-eyed, crying, and meltdown mode!
  - Emits heartbreak particles (`💔`) and screen wobble on each rejection.
  - Smoothly scales up the **"Yes"** button until it pulses with a glowing neon aura.
  - **Dodge Mode**: After 3 clicks, the "No" button begins playfully running away and teleporting when hovered or tapped!
- 🎵 **Web Audio API Sound Effects (Zero External Files)**:
  - Cute pop blips on button hover.
  - Playful downward boing/whimper when clicking "No".
  - Triumphant romantic fanfare arpeggios when saying "Yes".
  - Built-in soothing lofi chime melody with a toggleable music button (`🎵`).
- 🎉 **Full Confetti Cannon**:
  - Built-in native canvas confetti explosion when the user says "Yes".
  - "Celebrate Again" button for endless celebratory confetti.
- 💌 **Customizable Personalization**:
  - Use URL parameters: `?to=RecipientName&from=YourName`
  - Modal generator allows anyone to generate a personalized link in seconds and copy it to their clipboard!
- 🍝 **Interactive Date Planner**:
  - On the celebration page, pick from romantic date options (Romantic Dinner, Movie Marathon, Stargazing, etc.) with custom sound chimes and confetti bursts.
- 💌 **Animated Love Letter**:
  - Unfolds an interactive romantic love note.
- ⏳ **Real-Time Valentine's Day Countdown**:
  - Live days, hours, minutes, and seconds countdown to February 14.
- 📱 **100% Responsive & Glassmorphism Design**:
  - Frosted glass cards, gradient shifts, modern typography with Google Fonts (`Outfit`, `Pacifico`, `Caveat`).

## 🚀 How to Run Locally

1. Clone this repository or download the files.
2. Simply double-click `index.html` or open it in any web browser.
3. No build steps, Node.js, or external audio libraries required!

---

## 🔗 Personalized Links

You can customize the proposal by opening the site with query parameters:
```
index.html?to=Sarah&from=Alex
```
Or click the **✨ Personalize** button directly on the website to generate and copy a link automatically!
